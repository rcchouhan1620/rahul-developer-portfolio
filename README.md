# Rahul Chouhan — Developer Portfolio

Responsive modern-dark portfolio built with React + Vite.

## Run locally
1. Install Node.js LTS.
2. Extract the ZIP and open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite (normally http://localhost:5173).

## Before publishing
- Add your GitHub profile URL in `src/App.jsx` if you want a GitHub icon/link.
- Review all skills and project descriptions for accuracy.
- Add a resume download only after placing the current PDF in `public/`.
- Do not publish confidential employer/client code or data.

## Production
Run `npm run build`. Vite creates the deployable site in `dist/`.
Deploy to Vercel or Netlify with build command `npm run build` and output directory `dist`.
